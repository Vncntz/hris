## Acceptance criteria and required verification

- Index records Decision ID, title, detectable status, source and exact line range; only heading definitions count. Ranges end at next equal/higher heading. Master Plan has lookup precedence; cross-source duplicates remain visible; same-source duplicate definitions fail.
- Generated index is explicitly non-authoritative; generation is deterministic; `python tools/plan-index.py --check` returns 0 only for an exact current index and 1 for stale/missing output.
- `plan-get.py` reads the index, resolves an exact ID (and section name if unambiguous), and prints exact indexed source range with path and lines. Unknown, ambiguous, malformed, or stale ranges fail clearly.
- Agent state is local/advisory, ignored, and never proves a gate or overrides Git/GitHub. Governance documents lifecycle and reconciliation. `.cmd` remains CRLF; Unix wrapper/scripts remain LF.
- Run generation and `--check`, retrieve D-131, syntax-check Python, sample line ranges, verify ignore behavior, run `git diff --check`, and confirm frozen sources unchanged. Commit and open one Draft PR; gated automatic merge is authorized after every current gate passes.
