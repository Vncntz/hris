## Scope and acceptance criteria

1. Replace the placeholder root view with an authenticated `MainLayout` (Vaadin `AppLayout`)
   and a `DashboardView` at `/`. Both require authentication (`@PermitAll`); anonymous
   requests to `/` still redirect to `/login`.
2. The shell provides an application brand, a labelled main navigation built from Vaadin's
   access-filtered menu configuration (so later views appear only when the current user may
   open them), a current-view heading, the signed-in login name and a visible logout control.
3. Logout behavior is unchanged: it calls `AuthenticationContext.logout()` and returns to login.
4. The dashboard contains no fabricated metrics, business data or Client CRUD. It welcomes the
   signed-in user and honestly states that no business modules are enabled yet.
5. Responsive on representative desktop/laptop viewports, with the drawer collapsing to an
   overlay on narrow widths; keyboard reachable controls, accessible names, one `h1` per view
   and readable contrast. A consistent Vaadin theme applies to login and shell.
6. No internal identifiers, credentials, stack traces or infrastructure details are displayed.
