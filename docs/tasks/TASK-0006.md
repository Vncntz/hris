# TASK-0006 — Java codebase polish

Status: PLANNED; blocked until [TASK-0005](TASK-0005.md) merges, post-merge verification passes, and trusted-main gates are available. Parent: [IMP-087](../implementation/tasks/IMP-087.md).

## Goal and scope

Use only the Maven Wrapper in build instructions. Pin a verified stable Maven Enforcer version and require Java `[25,26)`. Add `shared-kernel` to root dependency management. Add loopback-only `application-dev.properties` without changing normal LAN binding. Strengthen the temporary Hibernate Validator exclusion guardrail. Replace brittle Vaadin smoke-test internals with a random-port HTTP GET of `/` that checks 200, HTML-compatible content type, and stable bootstrap evidence. Inspect actual generated frontend output before adjusting `.gitignore`.

## Non-goals and affected modules

No HRIS business behavior, authentication implementation, premature validation restoration, production binding change, or unrelated module dependency. Affects root build, `hris-app` resources/tests, proven generated-output ignores, and related documentation only.

## Relevant decisions and documents

Frozen Master Plan D-109, D-131, D-138; [execution rules](../implementation/EXECUTION_RULES.md); [Git Integration Agent procedure](../implementation/GIT_INTEGRATION_AGENT.md). Verify Enforcer version from official Maven documentation. No approved ADR applies.

## Acceptance criteria and required verification

- Enforcer pins a stable verified version and rejects Java outside `[25,26)`; dependency management includes `io.github.vncntz.hris:shared-kernel:${project.version}` without new cross-module dependencies.
- Normal application configuration remains LAN-capable; dev profile binds `127.0.0.1`. The Hibernate Validator exclusion guardrail requires restoration before validation annotations, validated DTO/forms, or config validation, and no later than validated authentication forms.
- Smoke test starts the embedded HTTP server and checks a real GET response; it does not assert internal bean names, servlet registration/mapping, or client-rendered view text. Only proven generated frontend output is ignored.
- Run full local Maven Wrapper `clean verify`, inspect test behavior/configuration, full diff and `git diff --check`, and confirm frozen sources unchanged and no new business behavior. Commit and open one Draft PR. Gated automatic merge is authorized only after every trusted-main gate passes.

## Documentation, security, audit, migration, deployment

Update build guidance and mutable state with verified facts. Loopback profile is for local development; production/on-prem LAN access remains configurable. No customer data, application audit, or database migration change.
